# "Marketplace" means a retail site; the offer catalog module is renamed

The word Marketplace is reserved for Amazon, Walmart, Shopify, and similar sales sites. `convex/marketplace.ts`, which exposes the catalog of offers that publishers browse, is renamed to `convex/offers.ts` with the same functions, and the offer catalog is referred to as the offer catalog in code and docs. One word with two meanings in the same schema was the alternative and was rejected.
