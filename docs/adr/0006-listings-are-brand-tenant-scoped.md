# Listings stay in the brand's tenant; cross-tenant discovery is deferred

`brandProducts`, `listings`, and `brandStorefronts` carry the brand's `tenantId` and follow the existing `networkAccess` rules, so only the brand workspace can read or write them today. Creator discovery and operator catalog views keep rendering fixture data until a network-wide read model is designed, because the alternatives (a cross-tenant `visibility` flag readable by any session, or mirroring brand writes into the operator tenant) would add the first cross-tenant read path or a second source of truth without a design for who may see what. This is a deliberate gap: the next decision in this area must define how a listing becomes visible to creators and operators.
