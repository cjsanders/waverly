Insights pages separate reach, attributed sales, and money you can expect to receive.

| Page        | What it is for                                                                   |
| ----------- | -------------------------------------------------------------------------------- |
| Performance | Connect content reach and engagement to attributed publisher outcomes.           |
| Reports     | Workspace reporting for the selected date range. Calendar days are shown in UTC. |
| Earnings    | Project fees, approval gates, and affiliate upside as separate earning events.   |
| Payouts     | Which publisher payments are in a settlement and when that settlement arrives.   |

Reporting dates use UTC so the first HTML and the browser show the same calendar day. Change the range from Performance or Reports; CSV export is available on reporting surfaces that list it.

Payout timing depends on the publisher or program that owes the balance. Earnings can include items that are not yet in a payout.
