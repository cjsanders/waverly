Organization pages are about the workspace itself, not a single campaign.

## Properties

Properties are the sites, newsletters, or channels attached to your publisher profile. Operators review submitted properties before some programs are fully available.

## Messages

Messages is included in the first HTML for the page: the inbox and the requested (or first) accessible conversation. Typing presence stays live in the browser. Switching workspaces starts a new document request so conversations cannot leak across organizations.

## Settings

Manage the workspace name, notifications, connected accounts, and payout preferences for this creator organization.

To open a different workspace — including a seller program — use the sidebar switcher. [Sellers](/sellers) documents the brand side of the same account.
