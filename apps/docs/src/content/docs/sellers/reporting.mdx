Reporting is scoped to the active brand workspace.

| Page         | What it is for                                                                            |
| ------------ | ----------------------------------------------------------------------------------------- |
| Performance  | Compare periods and marketplaces across clicks, conversions, sales, commission, and ROAS. |
| Deep reports | Halo revenue, new-to-brand acquisition, best-seller rank lift, and referral credits.      |

Calendar days are formatted in UTC so the server markup and the browser show the same day. CSV export is available on reporting surfaces that list it.

For invoices and platform fees, see [Billing](/sellers/billing).
