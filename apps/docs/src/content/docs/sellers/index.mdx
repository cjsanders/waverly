A seller workspace is a **brand** organization in the affiliate app. It is for teams that run campaigns, recruit creators, and pay commissions.

After you sign in, Waverly opens `/brand`. The sidebar follows the same groups as these docs: program setup, creators, reporting, finance, and the workspace.
