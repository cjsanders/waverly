Program pages are the catalog and commercial terms creators see.

| Page                   | What it is for                                                                               |
| ---------------------- | -------------------------------------------------------------------------------------------- |
| Brand profile          | Creator-facing profile, storefronts, contact details, and application policy per channel.    |
| Products & commissions | Activate catalog items, set public product rates, and grant private creator-specific boosts. |
| Deals & CPC            | Schedule promotions and fund click campaigns that fall back to CPA when the budget ends.     |
| Samples                | Review creator fit and trigger Amazon or Shopify fulfillment from the request.               |

Public commission rates apply to anyone in the program. Private rates override the public rate for a specific partner. Pause a product when it should stop generating new tracking links without deleting history.

Sample requests stay on this workspace. Approving a sample does not by itself create a paid placement; that lives under [Creators](/sellers/creators).
