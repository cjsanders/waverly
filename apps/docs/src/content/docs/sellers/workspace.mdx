## Messages

Messages is included in the first HTML for the page: the inbox and the requested (or first) accessible conversation. Use it to negotiate opportunities and resolve delivery questions in the same commercial context as the program.

Switching workspaces starts a new document request so conversations cannot leak across organizations.

## Settings

Manage the brand workspace, commerce connections, notifications, and billing preferences.

To open a creator workspace from the same account, use the sidebar switcher. [Creators](/creators) documents that mode.
