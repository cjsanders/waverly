---
title: Workspaces
description: Creator, brand, and operator modes, their URLs, and how to switch.
---

A workspace is a WorkOS organization. Its `metadata.kind` decides which mode of the affiliate app it opens in. You can belong to several workspaces and switch between them; the active WorkOS organization on your session is the one the app uses.

## Modes

| Kind     | Home        | What it is for                                                                                            |
| -------- | ----------- | --------------------------------------------------------------------------------------------------------- |
| Creator  | `/creator`  | Discover products, manage placements, and get paid for what you promote.                                  |
| Brand    | `/brand`    | Run a creator program, review applications, and pay commissions.                                          |
| Operator | `/operator` | Network-wide publishers, advertisers, and payouts. Provisioned by Waverly, not [onboarding](/onboarding). |

Organizations without a valid `kind` are ignored at sign-in and cannot open the app.

## Routes

Each mode lives under its own prefix. Visiting a prefix that does not match the active workspace sends you to that workspace's home. `/dashboard` is a leftover entry point: it signs you in if needed, then hops into the workspace layout (first `/creator`, which then redirects if your workspace is a brand or operator).

The selected page is the `page` search param — for example `/creator?page=Messages`. Invalid values fall back to Overview. The last page (and the overview journey step) is remembered in session storage for that organization.

If you have memberships but the session has no active organization yet — a fresh sign-up, or a membership added elsewhere — the app selects your first workspace and shows “Opening …” while the session updates.

## Switcher

The sidebar control shows the active workspace name and its kind (for example, “Creator workspace”). Open it to:

- See every workspace you belong to, with kind and role
- Switch to another workspace (the URL prefix and navigation change)
- Create another workspace via [onboarding](/onboarding)

Workspaces in the list are ordered operator, then brand, then creator, and alphabetically within each kind.

## Navigation

Sidebar items are grouped by section. Every item opens a real page; there is no “Coming soon” stub.

| Mode     | Sections                                                                                                                                                                                                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Creator  | **Home** Overview, Getting started · **Discovery** For you, Product catalog, Brand catalog, Cost-per-click, Loyalty programs, Lists · **Work** Opportunities, Projects, Portfolio, Partnerships, Placements, Tracking, Storefront · **Insights** Performance, Reports, Earnings, Payouts · **Organization** Publishers, Properties, Messages, Settings |
| Brand    | **Program** Overview, Brand profile, Products & commissions, Deals & CPC, Samples · **Creators** Creator directory, Applications, Partnerships, Paid placements · **Reporting** Performance, Deep reports · **Finance** Billing · **Workspace** Messages, Settings                                                                                     |
| Operator | **Network** Overview, Publishers · **Marketplace** Advertisers, Programs, Offers · **Performance** Links, Clicks, Conversions, Reports · **Finance** Balances, Payouts · **Operations** Providers, Messages, Settings                                                                                                                                  |

The overview header uses the workspace name (for example “Northstar Media overview” or “Network overview”). Creator **Getting started** is a pending-publisher review of the same seven-step journey.

The first time a workspace opens, the app seeds a development catalog for that organization only. It does not reset records that are already there. See [Affiliate network](/network) for what is persisted versus simulated.
