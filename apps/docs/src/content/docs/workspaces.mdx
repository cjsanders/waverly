---
title: Workspaces
description: Creator, brand, and operator modes, their URLs, and how to switch.
---

A workspace is a WorkOS organization. Its `metadata.kind` decides which mode of the affiliate app it opens in. You can belong to several workspaces and switch between them; the active WorkOS organization on your session is the one the app uses.

## Modes

| Kind     | Home        | What it is for                                                                                                   |
| -------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| Creator  | `/creator`  | Discover products, manage partnerships, track performance, and get paid.                                         |
| Brand    | `/brand`    | Run a creator program: catalog, applications, placements, and billing.                                           |
| Operator | `/operator` | Network-wide publishers, advertisers, links, and payouts. Provisioned by Waverly, not [onboarding](/onboarding). |

Organizations without a valid `kind` are ignored at sign-in and cannot open the app.

## Routes

Each mode lives under its own prefix. Visiting a prefix that does not match the active workspace sends you to that workspace's home. `/dashboard` is a leftover entry point: it signs you in if needed, then hops into the workspace layout (first `/creator`, which then redirects if your workspace is a brand or operator).

If you have memberships but the session has no active organization yet — a fresh sign-up, or a membership added elsewhere — the app selects your first workspace and shows “Opening …” while the session updates.

Pages inside a workspace are selected with a `page` search parameter, for example `/creator?page=Product+catalog` or `/operator?page=Messages`. An unknown page falls back to Overview. The selected page is also remembered per organization in browser session storage.

## Switcher

The sidebar control shows the active workspace name and its kind (for example, “Creator workspace”). Open it to:

- See every workspace you belong to, with kind and role
- Switch to another workspace (the URL prefix and navigation change)
- Create another workspace via [onboarding](/onboarding)

Workspaces in the list are ordered operator, then brand, then creator, and alphabetically within each kind.

## Navigation

Each mode has a full sidebar. Items open the matching page in the same workspace; they are not placeholders.

| Mode     | Sidebar groups                                             |
| -------- | ---------------------------------------------------------- |
| Creator  | Home, Discovery, Work, Insights, Organization              |
| Brand    | Program, Creators, Reporting, Finance (Billing), Workspace |
| Operator | Network, Marketplace, Performance, Finance, Operations     |
