Start here for product internals, WorkOS, and the local agent stack.

Cloud Agents run the credential-free local stack with `bun run setup:agent` and `bun run dev:agent`, then sign in through the [agent login](/internal/agent-login) route. That path is dev-only and never ships in production.

Waverly is an affiliate network. After you sign in to the affiliate app, you work inside a **workspace**. Each workspace is a WorkOS organization whose kind — creator, brand, or operator — picks the mode of the app and the URL you land on.

Signed-in users with no workspace go to `/onboarding`. Everyone else opens the home of their active
workspace (`/creator`, `/brand`, or `/operator`). `/dashboard` still works; it redirects into that
workspace layout. Workspace pages render on the server; Messages includes the inbox in the first
response.

Public docs for those modes live under [Creators](/creators) and [Sellers](/sellers). This Internal section stays off search, sitemaps, and `llms.txt`.
